# Glossaire

| Terme | Sens | Nom du projet |
|---|---|---|
| WebView | Contrôle qui affiche une page Web dans l’application | `WebView` |
| WebView2 | Moteur Chromium intégré fourni par Microsoft Edge | runtime WebView2 |
| onglet | Vue de navigation avec son URL et son historique | `Tab` |
| contexte | Profil partagé pour cookies, cache et données de navigation | `WebContext` |
| barre d’adresse | Champ qui ouvre une adresse ou lance une recherche | `address` |
| autosauvegarde mot de passe | Invite WebView2 pour enregistrer puis remplir un mot de passe | `SetIsPasswordAutosaveEnabled` |
